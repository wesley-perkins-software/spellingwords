SpellingWords.app is a spelling curriculum resource, not a vocabulary website. Vocabulary practice is useful, but the curriculum is organized around the spelling concepts students are explicitly expected to learn to encode.

## Audience

The site should be trusted by parents, classroom teachers, reading interventionists, literacy specialists, and homeschool families. Instructional writing should be friendly, technically accurate, concise, and encouraging.

## Curriculum stance

The curriculum reflects broad consensus across U.S. elementary literacy instruction, structured literacy practice, state standards, and common phonics sequences. It should not reproduce any one commercial curriculum.

## Site levels

### Level 1: Grade hubs

Grade hubs are roadmaps, not pacing guides. A grade hub should show the major spelling milestones for the year without exposing every tiny practice page.

Each grade hub has:

1. **Core Spelling Progression** — the main roadmap for the grade.
2. **Themed Spelling Practice** — optional support pages, targeted skill pages, and vocabulary pages.

### Level 2: Core instructional concept pages

Core units represent major spelling milestones. Each Core page teaches one instructional concept and should feel like a complete mini lesson.

Core pages should use approximately 8–16 carefully selected spelling words. They should not become giant word banks.

Each Core unit page should include:

1. Introduction: what students learn.
2. Learning Objectives.
3. Why this spelling concept matters.
4. Parent-friendly explanation.
5. The spelling rule or generalization.
6. Practice word list.
7. Example sentences.
8. Common mistakes children make.
9. Common Misconceptions.
10. How parents can practice at home.
11. Navigation links to the previous lesson, next lesson, related targeted practice, Kindergarten review when appropriate, and Grade 2 extension when appropriate.

### Level 3: Targeted practice pages

Targeted practice pages focus on narrow skills such as SH words, CH words, BL blend words, long A silent-e words, or OA words.

These pages remain valuable for SEO, GEO, AEO, intervention, internal linking, and teacher assignment. They should be preserved whenever useful and related from the appropriate Core units.

## Vocabulary pages

Vocabulary pages supplement the curriculum. They do not define it.

Pages such as Everyday Words, Action Words, Describing Words, Animals, Weather, or Transportation can remain as additional practice, writing support, or topical reinforcement. They should not replace the grade-level spelling progression.

## URL and content preservation

Preserve existing URLs wherever possible. Do not delete useful content. Repurpose, relate, and cross-list existing pages before creating replacements or changing grade ownership.

When a page from another grade supports a current grade's roadmap, prefer cross-linking it from the Core page rather than physically moving it, unless there is a compelling reason to change its canonical grade.

## Navigation requirements

Core pages should make the curriculum path obvious:

- previous Core lesson,
- next Core lesson,
- related targeted practice,
- Kindergarten review when helpful,
- Grade 2 extension when helpful.

Grade hubs should remain clean and should not list every targeted practice page in the main roadmap.

## Canonical implementation model

Kindergarten is the canonical model: a curated Core Spelling Progression plus Themed Spelling Practice. Future grade redesigns should follow the same philosophy and use hand-maintained progression data instead of relying only on broad content categories.
