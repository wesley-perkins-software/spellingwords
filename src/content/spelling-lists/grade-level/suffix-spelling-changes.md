Some suffixes attach directly to a base word with no changes. Others trigger a small, predictable change to the base word right before the suffix is added. Short-vowel words ending in one consonant double that consonant (*run* to *running*). Words ending in a silent e drop the e before a vowel suffix (*make* to *making*). Words ending in a consonant plus y change the y to i (*carry* to *carried*). Each is a different starting shape, so checking the base word first tells a speller which rule applies.
