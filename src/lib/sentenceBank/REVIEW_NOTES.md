# Sentence Bank — Review Notes

This file tracks words from the curriculum source that were **deliberately not
added** to the sentence bank because they need editorial review. The bank is
built incrementally, prioritizing educational usefulness over completeness, so
problematic words are skipped rather than forced in.

**Source:** Reading Rockets _Basic Spelling Vocabulary List_
(https://www.readingrockets.org/topics/writing/articles/basic-spelling-vocabulary-list)

---

## Grade 1

### Skipped — needs review

- **may** — Ambiguous / proper noun. The modal verb "may" collides with the
  month and given name "May," and a single short, concrete sentence can't make
  the intended meaning clear for a young speller.
- **will** — Ambiguous / proper noun. The modal verb "will" collides with the
  given name "Will" and the noun "will," so it can't be demonstrated cleanly
  without risking confusion.
- **oh** — Interjection. "Oh" carries no concrete meaning to illustrate; any
  sentence demonstrating it is an exclamation rather than a concrete,
  age-appropriate example.
